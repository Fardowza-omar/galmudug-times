# Galmudug Times - News Portal

A professional news portal built for Galmudug Times. Clean, fast, and fully responsive.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Status](https://img.shields.io/badge/status-active-success.svg)

## Features

- **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- **Breaking News Ticker** - Animated scrolling ticker for urgent news
- **Categories** - Politics, World, Business, Technology, Opinion, Culture
- **Search** - Full-text search across all articles
- **Comments & Likes** - Reader engagement features
- **Media Support** - Images and embedded videos

## Getting Started

### Prerequisites
- Node.js 14+ installed
- npm

### Installation

```bash
git clone https://github.com/Fardowza-omar/galmudug-times.git
cd galmudug-times/api
npm install
npm start
```

The site will be available at **http://localhost:3000**
